# 同频猜词

游玩地址：https://hdorku.github.io/tongpin-game/

两个人每轮各写一个词，双方提交后一起揭晓，根据上一轮继续联想。相同词自动通关；意思相近时，双方都确认才通关。

## 使用

1. 一人创建房间，复制邀请链接发给朋友。
2. 朋友打开链接，填昵称加入。无需注册、无需飞书账号。
3. 两个人都保持游戏页面打开。支持刷新恢复当前席位；主动离开、关闭页面或清除浏览器存储可能结束房间。

## 运行与发布

```sh
npm ci
npm test
npm run dev
npm run build
```

已发布源码到 https://github.com/hdorku/tongpin-game 。在 Settings → Pages 中选择 Deploy from a branch → main → /(root)。`index.html` 是构建生成的独立网页（头像文件为同目录的 `avatar.jpg`），可直接由 GitHub Pages 托管。开发入口是 `/dev.html`，可编辑同目录的 `main.js`、`room.js`、`game.js` 和 `style.css`；执行 `npm run build` 会重新生成根目录与 dist 中的 index.html，提交更新即可自动发布。房间邀请使用查询参数，刷新无需服务器路由。

## 联机与隐私

GitHub Pages 只托管静态网页。联机使用 PeerJS 的公共信令服务与 WebRTC DataChannel，两名玩家的浏览器负责房间状态与游戏同步，不依赖妙搭数据库。PeerJS 在建立连接时接收临时连接标识与必要的网络信息；游戏词语经浏览器之间的数据通道传输，不发送至 GitHub 仓库。没有摄像头、麦克风或地理位置权限请求。

双方锁词先交换带随机盐的 SHA-256 承诺，两个承诺都收到后才交换词语；词语、局数、轮次和随机盐绑定，避免提前读取和锁定后改词。浏览器 sessionStorage 保存本页的重连信息与当前游戏。此游戏面向朋友休闲共玩，不提供对恶意修改客户端的竞技裁决。

**网络限制**：依赖公共信令服务的可用性。部分公司网络、VPN 或严格 NAT 可能阻断 WebRTC；连接失败时会提示并自动重试，可切换网络。仓库未配置商业 TURN 中继，不能保证所有网络组合都可连接。需要保证复杂网络连通时，可增加自有 PeerServer 和经授权的 TURN 服务（不应把私密 TURN 长期凭据放在静态源码中）。

**房间生命周期**：房主页面负责协调，房主关闭或退出时不能继续游戏；刷新会尝试恢复连接与状态。没有离线持续运行的服务器，也不提供跨设备接管旧席位或永久对局存档。

## 验证

`npm test` 验证答案保密、提交后禁止改词、轮次校验、双方同义确认、双方进入下一轮/重开、历史记录、房满、规范化同词以及刷新状态恢复。浏览器联机与布局的实际验收记录见 `VERIFICATION.md`。
